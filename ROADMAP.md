# Roadmap

This file records the project's short-term / mid-term / long-term plans.

- There may be many planned items, or it may be empty for a while.
- Update frequency is irregular (updated from time to time as appropriate).
- When new planning content appears here, it usually means these directions **are not necessarily** going to be released by the author immediately in the short term, but are made public first so interested contributors can participate.

## Contribution Coordination

If you are interested in a planned feature and intend to implement it, please open an Issue first explaining:

1. Which planned feature you intend to implement;
2. Your implementation idea (briefly);


This reduces duplicate work or conflicts with other contributors.

When the feature is done, the PR is submitted and accepted, please close the corresponding Issue.

### Suggested Issue Title Format

To make it easy to quickly distinguish "plan claims" from normal issues, use the following title format:

- Claim a planned item: `[Claim][Module] feature name`
- Proposal discussion: `[Proposal][Module] topic`

Examples:

- `[Claim][Workflow] Enhance the workflow visual-debug panel`
- `[Proposal][AI Generation] State-machine optimization for instruction-stream multi-round feedback`

It is recommended to attach in the Issue body:

1. Planned implementation scope (what to do / what not to do)
2. Expected timeline (optional)
3. Whether collaboration is needed
